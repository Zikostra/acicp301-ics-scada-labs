## Repository Structure

Each laboratory has its own directory containing:

- a practical report in `README.md`;
- clearly labelled evidence;
- technical observations and analysis;
- supporting project files where required by the assessment.

## Laboratory Scope

All activities documented in this repository are restricted to ICDFA-provided virtual machines, isolated training networks, supplied packet captures and authorized laboratory resources.

No production, organizational or public infrastructure is used for the practical work.

INTERPRETATION
FUXA at 192.168.57.101 requested one input register from OpenPLC
at 192.168.57.102 using Modbus Function Code 04. The requested
register was Input Register 80, which is mapped to the Tank Level
value in the TankFillSim process. OpenPLC returned the value 8.
The identical Transaction ID 79 links the request and response.
